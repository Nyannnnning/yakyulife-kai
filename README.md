# 棒球生涯模擬器 ⚾

這是一款純文字的棒球生涯養成遊戲。玩家從 1990 年、台灣職棒剛亮燈的那一年開始，經歷青棒、選秀、旅外、國際賽、聯盟興衰與黑霧年代，直到引退。

👉 **[點我直接遊玩](https://nyannnnning.github.io/yakyulife-kai/)**

## 遊戲特色
* **多層級聯賽**：完整模擬高中、大學、業餘成棒、中職、日職與大聯盟的升降級與合約交涉。
* **1990 年代篇**：球隊、盃賽、國際賽與聯盟版圖隨年份改變；名稱全為虛構影射。
* **美日年代事件**：旅日與旅美不再只是換一組數值；自由球員制度、跨海先驅、跨聯盟賽、勞資停擺、藥檢與球員會風暴會按年份登場。
* **球員咖位分歧**：邊緣人、一軍主力、明星球員與聯盟門面會遇到不同人物、對話、難度與後果。
* **年代成就與生涯印記**：重大選擇會解鎖正面成就或負面印記，並直接加減各聯盟生涯評價；十八歲巴塞隆納末席與牛肉麵奇蹟也有專屬成就。
* **D20 關鍵判定**：高風險劇情公開顯示能力、修正值、難度與優勢／劣勢；道德選擇不交給骰子。
* **可玩的黑暗路線**：玩家可以拒絕、通報，也可以主動收下信封並承受之後的證據、危險與處分。
* **衰退期禁藥線**：能力開始下滑後，有機率遇到禁藥誘惑；拒絕、求助、使用、停用與否認會一路影響藥檢、停賽、成就與引退評價。
* **極低機率搞笑線**：有旅美經歷的投手在重大手傷復健後，可能回家賣牛肉麵，喝完自己的湯突然痊癒，再從美國職棒不同層級復出。
* **養成週期**：每年先定養成目標並經春訓驗收；目標影響當季狀態、教練信任與傷病管理，永久成長仍沿用原作者的訓練骰、大賽與國際賽能力點。
* **隱藏屬性系統**：包含天才、鐵人等豐富的隱藏特質。
* **人生隨機事件**：感情選擇、傷病危機、公關事件與國際賽徵召，球場外的每一個決定都會影響生涯走向。
* **細緻的數據運算**：依照球探量表 (20-80) 進行能力養成，並根據不同守備位置與角色定位給予專屬評價。

## 本機開發

本專案沒有外部套件或建置步驟，直接開啟 `index.html` 即可遊玩。

主要檔案：

* `index.html`：頁面結構與遊戲介面。
* `styles/game.css`：所有視覺樣式與響應式版面。
* `src/game.js`：遊戲資料、規則、流程與畫面互動。
* `scripts/verify-project.mjs`：零依賴的結構與核心規則檢查。

修改後可執行：

```bash
npm test
```

若 Windows PowerShell 阻擋 `npm.ps1`，請改用 `npm.cmd test`。

檢查內容包含 JavaScript 啟動、固定種子重現、能力值範圍、關鍵資料表與核心規則。
